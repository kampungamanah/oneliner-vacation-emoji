# oneliner-vacation-emoji

## Entry

One emoji for the dream vacation: dawn on a beach, the sun lifting out of the sea, the sand still empty and the whole day ahead of you.

`main.ts` writes it to `/output/entry.txt`:

## How to run

The entry lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set, otherwise in `/output/entry.txt`.

## Note

Sunrise beats sunset: it is the morning you have been dreaming about, not the day already spent — the trip is still ahead of you.
